Java GC Benchmark Docker

A comprehensive Docker-based benchmarking suite for Java Garbage Collection performance analysis and optimization

Get Started on GitHub

Why Choose Java GC Benchmark Docker?

Multiple GC Algorithms

Test and compare G1, ZGC, Shenandoah, Parallel, and CMS garbage collectors in standardized environments

Docker Containerization

Consistent, reproducible testing environment across different platforms and operating systems

High-Memory Benchmarks

Specialized benchmarks for high-memory scenarios with 16GB, 32GB, and 64GB heap configurations

Detailed Performance Metrics

Comprehensive reports on pause times, throughput, memory usage, and GC efficiency

Easy Configuration

Docker Compose files for different memory scenarios and simple shell scripts for execution

Analysis Tools

Python scripts for quick analysis and performance comparison across different configurations

Supported Garbage Collectors

G1 GC

Garbage-First
Default in modern Java

ZGC

Z Garbage Collector
Low-latency for large heaps

Shenandoah

Concurrent compacting
GC with low pause times

Parallel GC

Throughput-oriented
High-performance collector

CMS GC

Concurrent Mark Sweep
Legacy low-pause collector

Quick Start Guide

# Clone the repository git clone https://github.com/sbusanelli/java-gc-bench-docker.git cd java-gc-bench-docker # Run standard benchmark docker-compose up # Run high-memory benchmark (16GB) docker-compose -f docker-compose-high1.yml up # Run high-memory benchmark (32GB) docker-compose -f docker-compose-high2.yml up # Run high-memory benchmark (64GB) docker-compose -f docker-compose-high3.yml up
